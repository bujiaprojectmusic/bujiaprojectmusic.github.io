# Créditos de las fotos — Volumen 00 (edición de prueba)

Las 15 fotos de este volumen son **fotos propias del taller Bujía Project
Music** que ya estaban en este repositorio (`src/assets/img/`). Se copiaron
acá, byte a byte, para que el volumen de prueba viva completo dentro de
`vol-00/` y se pueda borrar de un tirón. No se usaron bancos externos
(Unsplash/Pexels) porque desde el entorno donde se armó el volumen no hay
acceso a esos sitios; cuando se quieran fotos de banco, van acá con su
licencia.

IMG_3223 e IMG_3224 (local viejo) **no** se usan.
